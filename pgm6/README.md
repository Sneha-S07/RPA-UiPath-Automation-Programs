# Word Document Automation using UiPath Studio X 📝

## 📌 Objective

To develop a Word Automation workflow using **UiPath Studio X** to demonstrate various operations on Microsoft Word documents.

## ⚙️ Activities Demonstrated

This program covers the following activities:

1. **Use Word File** – Opens and works with an existing Word document.
2. **Save Document As** – Saves the Word document with a specified name or location.
3. **Read Text** – Extracts text content from a Word document.
4. **Replace Text in Document** – Searches for and replaces specific text in the document.
5. **Append Text** – Adds new text to an existing Word document.
6. **Replace Picture** – Replaces an existing picture in the document with another image.
7. **Add Picture** – Inserts a picture into the Word document.
8. **Save Document as PDF** – Exports the Word document as a PDF file.

## 🛠️ Tools & Technologies

## 🚀 Workflow

The automation workflow demonstrates how UiPath Studio X can interact with Microsoft Word documents to perform text editing, image manipulation, document saving, and PDF conversion.

- Reading and modifying Word document content.
- Performing text replacement and appending operations.
- Adding and replacing images in documents.
- Saving Word documents in different formats, including PDF.
