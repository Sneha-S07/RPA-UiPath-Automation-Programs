# Window Management using UiPath Studio X 🖥️

## 📌 Objective

To develop a UI Automation workflow in **UiPath Studio X** to demonstrate various window management activities.

## ⚙️ Activities Demonstrated

This program covers the following UiPath activities:

1. **Get Active Window** – Identifies and retrieves the currently active application window.
2. **Maximize Window** – Maximizes the selected window.
3. **Minimize Window** – Minimizes the selected window.
4. **Hide Window** – Hides the selected window.
5. **Restore Window** – Restores a minimized or maximized window to its previous state.
6. **Move Window** – Changes the position of the selected window on the screen.

## 🛠️ Tools & Technologies

- UiPath Studio X
- UI Automation Activities
- Windows Desktop Environment

## 🚀 Workflow

The automation workflow demonstrates different operations that can be performed on an active application window using UiPath Studio X.

The activities are configured to retrieve the active window and perform the required window management operations.

## 🎯 Learning Outcomes

- Understanding UI Automation in UiPath Studio X.
- Working with active application windows.
- Performing window management operations.
- Understanding how UiPath interacts with desktop applications.
