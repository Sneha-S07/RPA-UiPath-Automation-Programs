# UiPath Automation Programs 🤖

Welcome to my **UiPath Automation Programs** repository!

This repository contains my hands-on practice programs and projects developed using **UiPath Studio** as part of my learning journey in Robotic Process Automation (RPA).

The goal of this repository is to document my learning, improve my automation skills, and build practical solutions for automating repetitive tasks.

## 📂 Repository Contents

The repository includes automation programs related to:

- **Excel Automation** – Automating spreadsheet operations and data processing.
- **Browser Automation** – Automating web browser interactions.
- **Email Automation** – Automating email-related tasks.
- **File and Folder Automation** – Creating, managing, and organizing files and folders.
- **PowerPoint Automation** – Automating presentation-related tasks.
- **Basic UiPath Programs** – Practicing variables, activities, control flow, and workflow design.
- **Mini Projects** – Combining multiple UiPath activities to solve practical automation problems.

## 🛠️ Tools & Technologies

- UiPath Studio
- Robotic Process Automation (RPA)
- Workflow Automation (XAML)
- Excel and Microsoft Office Activities
- UI Automation

## 🚀 Getting Started

1. Clone or download this repository.
2. Open UiPath Studio.
3. Open the required project folder.
4. Open the project using its `.uiproj` file or the project entry in UiPath Studio.
5. Restore any required dependencies.
6. Run the workflow using UiPath Studio.
